# 弹钢琴电脑音乐工作室 desktop44-port1 · 2026-10-23

独立入口 /pocket-piano/web/，网站首页的弹钢琴「网页版」按钮进入这里。以电脑键盘和鼠标为默认操作，把手机 1.0.41/code42 的演奏功能适配到桌面工作区。左侧曲库、中央当前乐器、下方钢琴与固定播放控制各有清楚位置；乐器选择和演奏工具按需打开。参考 Everyone Piano 的键盘操作关系及 Synthesia 的练曲视图，设计为本项目原创，不声称复制其完整默认键位或皮肤。

## 使用

直接按电脑键盘演奏，主 Enter 开始/暂停，按住空格延音，Esc 停止声音；Shift 加发音键使用半音。逐键音高、左右手八度、力度和笔记本布局在电脑键位的设置里调整。钢琴可切换单行、双行、自动续行、7–52 白键宽度、音区、标签、移调、四种外观和六组颜色。

左上乐器入口包含钢琴、音乐计算器、多彩打击垫、科学仪器、弦乐/管乐/口琴/吉他面板、音乐掌机、两种流光谱面及独立的十五种音乐光影。音色库共 176 个音色，默认继续用电脑键盘，也可明确选择对应乐器面板。各面板的键盘按键和鼠标位置来自同一映射，不重复触发声音；面板设置在演奏工具中。

演奏工具包含练习难度、左右手及声部筛选、等待与自动补奏、节拍器、六组和弦、A–B 循环、0.25–2 倍速、MIDI 导入/导出与外接 MIDI、录制及记录。吉他有六组和弦、两种扫弦节奏、速度和长度。完整曲谱窗口支持简谱/五线谱分页、缩放、当页 SVG/PNG 和全曲打印；浏览器打印中可选择另存为 PDF。

「纯净模式」只保留当前乐器或演奏画面，隐藏曲库、工具条、状态和多余标签。Esc 或浮现的退出按钮返回工作室；它与浏览器全屏独立，不改变曲目、播放方式、进度或键位。视频可选择纯净画面与横屏/竖屏，生成结束或失败后恢复原先显示状态。另有「纯净录屏」用于实时录制手弹或自动弹奏：在浏览器提示中选择当前钢琴标签页，声音直接来自本应用音源，不采集麦克风；F9 或浏览器停止共享结束并下载。录屏按浏览器实际支持的 WebM/MP4 格式命名，与整首曲目离线生成 MP4 分开。

## 直接运行与恢复

1. 获取[公开仓库](https://github.com/wjycoolman-cpu/xiaozhan123-cn-site)，保留目录结构。
2. 将本适配源码 ZIP 解压至仓库根目录，覆盖 pocket-piano/web/ 对应文件。
3. 在仓库根运行 python -m http.server 8769 --bind 127.0.0.1。
4. 打开 http://127.0.0.1:8769/pocket-piano/web/。需要 HTTP/HTTPS 源及浏览器音频手势，不能用 file:// 打开。
5. 共享音源、曲库及固定版本第三方依赖仍在相邻的 /demo/，不能只拷贝 web 而丢失共享资源。

## 加载与数据

默认键盘和菜单不等待曲库、谱面、整首音色或其他乐器。16 首内置曲目使用轻量索引，选中后才读取单曲；15,134 条历史曲库快照在用户打开在线曲库后加载，完整搜索在 Worker 中运行。五线谱、完整曲谱、各乐器与媒体导出分别动态加载，关闭或切换后使过期结果失效。屏显使用系统中文字体，默认不请求约 8MB 的 Noto 字库；仅在明确要求嵌入字体的导出或全曲打印时读取原有 OFL 字体。

声音继续使用原采样、TeaVM Java DSP 和 TinySoundFont/WASM。desktop-audio-worklet.js 与 desktop-offline-audio.js 在同一混音器中增加 170–175 六种簧片 DSP，保留原 0–169 的实现。算法来自手机 DeltaHarmonicaSynth.java 的逐浮点移植，原始 Java、音色定义、音孔映射及来源记录随源码提供。后台预热不创建 AudioContext；首次声音仍需浏览器手势和实际音源就绪。自动播放准备起始短窗，跟弹准备当前音组，再滚动预取，不等待整首采样。

旧 piano-web-songs、piano-web-favorites、piano-web41-keys 保留。继续使用 piano-web42-session 与 piano-web42-last-song，兼容旧 41/42/43 会话；旧手机八白键偏好不覆盖电脑首次 36 白键。刷新恢复为暂停。曲库、收藏、录制、键位和偏好保存在当前浏览器；不会由演奏页面上传。分包内存缓存不等于手机随包全曲库，也不承诺完整离线缓存。

## 性能记录与验收边界

帮助中的性能记录仅保存在本页内存，最多 112 条、同种操作最多 16 条；刷新重置，用户明确点击后才下载，不自动上传。固定名称与时间记录覆盖菜单、乐器切换、视图、选曲、音源、录制及导出；不收集曲谱、录音、搜索词、按键内容或身份。资源路径删除查询参数、匿名化单曲/采样/分包编号。可选诊断模块失败不影响演奏。

DOM/数据就绪、音频命令就绪和两次 rAF 后的呈现机会各有不同标记，隐藏页不记作已显示。这些时间不证明实际像素已显示、扬声器发声、INP 或冷/热启动通过。仓库依赖字节也不等于浏览器传输量或加载时间。

真实模块的 Node 状态/所有权/独立排谱/离线 PCM 对照验证，不能代替实际浏览器观感、字体排版、键鼠手感、声音听感、GPU 图像、PNG/PDF 或 MP4 导出验收。当前支持的浏览器宿主仍明确拒绝使用，因此这些实际体验保持未验证；不能用模型或资源 HTTP 成功冒充通过。
