来源与许可

网页版使用本项目原有的声音引擎、曲库和演奏模型；电脑按键图、浏览器输入及五线谱演奏由本项目适配。第三方代码、采样和曲目分别保留原许可。

电脑按键参考

参考 Everyone Piano 的左右手分区、音级提示及逐键自定义操作方式。字母区经典音阶行亦交叉参考作者公开的 Arduino Keyboard Piano 说明；附加小键盘键位、快捷键和笔记本半音布局属于本网页适配，不声称是 Everyone Piano 官方默认键位的完整复制，未复制其程序、图标或皮肤。

五线谱

VexFlow 4.2.5（MIT）负责谱面绘制，内置 Bravura 记谱字体（SIL Open Font License 1.1）与 Noto Sans SC（SIL Open Font License 1.1）用于谱面文字。保留两者许可，字体只由本网站的既有资源加载。演奏数据生成近似谱面，拍号、调号、时值量化与声部分配属于排版推定，非原版出版谱。

VexFlow 许可 · Noto 字体许可 · Bravura 字体许可

声音

沿用正式浏览器版的 170 种音色：TinySoundFont（MIT）与 TimGM6mb.sf2（GPL-2）提供 128 个 GM 音色，其余 42 个 Java DSP 音色经 TeaVM 0.12.3（Apache-2.0）编译；没有用通用振荡器替代原声音。钢琴采样为 Alexander Holm 的 Salamander Grand Piano（CC BY 3.0），使用既有 48 kHz 单声道子集，并非完整 16 层力度库。

声音来源与修改 · 采样库版权 · TeaVM 许可

曲库与本地数据

复用正式版 16 首随包曲谱及原有 15,134 个可解码的公开仓库历史快照条目，联网按需读取分包。这不代表当前官网实时全库，也不代表各作品及现代编配权利已逐首确认。自行导入的 MIDI、EOP、JSON、录制音符、收藏和键位偏好保存在当前浏览器，不由演奏页面上传。
