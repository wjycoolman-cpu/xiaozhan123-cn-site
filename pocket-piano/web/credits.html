五线谱

VexFlow 4.2.5（MIT）负责谱面绘制，使用内置 Bravura 记谱字形（SIL Open Font License 1.1），普通文字使用系统字体。既有 Noto Sans SC（SIL Open Font License 1.1）资源许可保留，屏显不请求整套中文字体；只有明确嵌入或全曲打印时读取原有 OFL 字体。演奏数据生成近似谱面，拍号、调号、时值量化与声部分配属于排版推定，非原版出版谱。

声音

常用钢琴音色沿用正式浏览器版的声音引擎与资源：TinySoundFont（MIT）与 TimGM6mb.sf2（GPL-2）提供 128 个 GM 音色，原有 42 个 Java DSP 音色经 TeaVM 0.12.3（Apache-2.0）编译；另将手机 1.0.41 的六种独立簧片 DSP 逐浮点移植到网页，合计 176 音色；没有用通用振荡器替代原声音。钢琴采样为 Alexander Holm 的 Salamander Grand Piano（CC BY 3.0），使用既有 48 kHz 单声道子集，并非完整 16 层力度库。
