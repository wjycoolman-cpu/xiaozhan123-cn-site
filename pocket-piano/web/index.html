PRACTICE

演奏设置

逐键音高、左右手八度与力度可在「电脑键位」中的「键盘设置」调整。原谱音高始终保持，可见琴键只决定显示范围。
KEYBOARD FIRST

双手放在键盘上，就能弹

字母区左手音区。按键图显示对应的音级与音高。
数字小键盘右手音区；无小键盘可切换「笔记本半音布局」。
Space按住延音，松开释放。
Enter开始 / 暂停。小键盘 Enter 是独立音符键。
Shift + 音符键经典布局升半音。
Esc立即停止声音。

右键按键可编辑映射。输入框、设置弹窗和浏览器快捷键保持正常。和弦逐音按对才推进，重复音需松开再按。部分实体键盘会限制同时按下的按键数。
EXPORT

保存你的演奏

选择一首曲目后，可以导出曲谱、音频和实际演奏画面。

音频和视频在点击生成时才准备资源。
