# 简历工坊 1.0.1 使用说明

简历工坊是一款本机使用的 Android 简历应用。**先导入或填写资料，再挑选模板，同一份信息会自动匹配进所选简历样式。**还没填写资料，也可以先看模板的完整示例效果。资料、照片、模板、PDF 生成和备份都可以离线完成，无需注册账号。

## 1. 安装

1. 将 `简历工坊-1.0.0.apk` 复制到手机，在文件管理器或下载列表中打开。
2. 按 Android 安装界面提示安装。若系统要求允许当前文件管理器或浏览器安装应用，按系统说明完成本次安装；无需授予通讯录、整机存储或网络权限。
3. 安装完成后，打开“简历工坊”。第一次使用可选择“先看模板”浏览完整示例，也可直接填写或导入自己的资料。

本次安装包沿用 `简历工坊-1.0.0.apk` 文件名以替换原有入口，安装后的实际应用版本为 **1.0.1**。更新时安装同签名包，可以保留已有资料；建议先备份。

支持 Android 8.0 及以上。文字 PDF 导入依赖较新的 Android System WebView；手机系统达到 Android 8.0，并不保证旧 WebView 已支持该导入功能。其他资料录入、模板和原生 PDF 导出可独立使用。

APK 是本地制作的安装包，没有应用商店发布或在线更新渠道。系统安装界面的提示取决于手机型号和设置。

## 2. 先导入信息，再选简历

在“资料”页点击“导入”打开资料导入界面，也可以直接填写姓名、求职意向、电话、邮箱、所在地、个人简介、教育经历、工作经历、项目、技能、证书、语言、奖项及自定义栏目。

| 导入方式 | 用法与范围 |
|---|---|
| 粘贴文字 | 把旧简历文字粘贴进导入框，在本机识别并整理。 |
| TXT | 导入文本简历；尝试 UTF-8，必要时兼容 GB18030 编码。 |
| Word DOCX | 提取正文文字；原文件的复杂排版、图片和完整表格结构不会直接保留。旧 DOC 请先另存为 DOCX。 |
| 文字 PDF | 提取可读文字，最多读取 30 页；扫描件、图片型 PDF 没有 OCR，不能自动识别图片中的文字。 |
| JSON | 导入兼容 JSON Resume 字段，或恢复本应用的全量 JSON 备份。 |

文件导入上限为 12 MB。加密 PDF 请先用原软件导出未加密副本。导入先显示识别结果供你校对，确认后新增简历，已有简历会保留。

自动识别需要检查姓名、联系方式、日期、公司和学校、经历分组；未匹配的文字会保留到“自定义 → 导入待整理”。导入后可以继续编辑，识别结果不会锁定。

## 3. 照片

在资料页选择照片，通过系统文件选择器导入。优先使用 JPG、PNG 或 WebP，选择后可以在本机调整裁剪范围、位置及缩放。

照片是选填项。预览设置可控制照片显示和形状；更换或关闭照片不需要重新录入简历内容。DOCX 或 PDF 中的照片需要单独选择导入。

## 4. 选择模板，自动匹配信息

首页“先看模板”仅进入图库浏览，不新增简历。进入“模板”页后，可浏览缩略图、按类别筛选或搜索，打开详情看完整排版，再点击“使用这款模板”。已填信息会自动套入所选样式，切换模板保留同一份资料。

**不用先填写，也能看清模板具体样子：**资料为空时，模板详情和主预览页默认显示“示例效果”，包含虚构姓名、经历、技能及绘制的头像，并标明“虚构示例 · 仅用于看样式”。示例只供查看，不会填写到个人资料、不会新增简历，也不会进入备份。

模板详情和主预览页均可切换“示例效果／我的资料”。填写或导入自己的信息后，再打开详情或主预览，默认显示“我的资料”。需要对比样式时，也可主动切回示例；再次切换即可核对自己的内容。

应用包含 **40 个基础设计族 × 25 组配色与排版预设，共 1,000 款可选样式**。这表示一千种可选择的样式组合，不代表一千套完全独立的排版结构。可收藏常用样式，未填写的栏目会自动隐藏。

进入“预览”后留意当前选择的是“示例效果”还是“我的资料”；投递前应核对“我的资料”中的实际姓名、照片和经历。缩略图主要用于看模板结构，需要看清正文时可使用“放大查看”。

## 5. 一页或两页

简历默认以**一页 A4**为目标，也可以选择**两页**。应用会在可读范围内尝试适配内容；内容较多、照片较大、段落较长或栏目较多时，仍可能超过目标。

预览设置可调整字号、行距、页边距、颜色、照片及栏目顺序。导出时会检查生成 PDF 的实际页数：

- 一页目标超出时，提示精简内容或改为两页。
- 两页目标仍超出时，提示精简内容。
- 超限时停止保存和分享；不会裁掉多出来的内容，也不会无限缩小文字。

遇到超限，可缩短重复描述、减少空行、隐藏暂不需要的栏目、关闭照片显示，或选择更适合信息量的模板，再核对完整预览。

## 6. 保存 PDF，分享给 QQ 或微信

PDF 始终使用你填写或导入的实际资料。资料为空时点击保存或分享，会提示“先填写你的资料”；可以继续看模板或去填写，不会把虚构示例导出为你的简历。

已有资料但正在查看“示例效果”时，点击保存或分享会先切回“我的资料”，并弹出“导出你的简历”确认框。核对排版后选择“导出我的简历”继续，也可先返回检查资料。

确认后选择“保存为 PDF”，使用系统文件界面选择保存位置。导出的是 A4 PDF 文件，方便打印、投递和通过聊天应用发送。

也可选择“分享文件”、QQ 或微信。手机安装并支持接收 PDF 的目标应用可被唤起；目标不可用时会打开系统分享面板。随后由你在接收应用中选择联系人并确认发送。

**打开分享面板或聊天应用不表示对方已收到文件。**接收应用、联系人选择、实际发送和网络状态由手机上的 QQ、微信或其他接收应用处理。简历工坊本身没有网络权限；聊天应用发送文件时使用其自己的网络。

取消保存或分享后，资料仍保留。为便于管理，可以先保存 PDF，再从聊天应用中选择该文件。

## 7. 自动保存、多份简历与备份

编辑内容会自动保存到本机，留意界面中的保存状态。若显示“未保存，请备份”，应先导出备份再关闭应用。

可管理最多 50 份简历，支持切换、复制、改名和删除。针对不同岗位，可复制一份再调整经历描述；删除前会确认。

在“我的”选择“备份全部简历”，保存全量 JSON 备份，包含资料、照片、模板设置及收藏。以后通过“导入资料”选择该备份恢复，恢复会新增记录并保留已有简历。

当前资料 JSON 用于字段交换，全量备份用于完整恢复；两者用途不同。卸载、清除应用数据、更换手机或升级前，请先导出并核对备份文件。应用没有云同步，也不依赖 Android 云备份。

## 8. 隐私与反馈

个人资料和照片保存在应用私有目录。导入、裁剪、模板预览和 PDF 处理均在本机完成，没有账号、广告、追踪或在线更新源。APK 没有 INTERNET 权限。

问题反馈只在本机保存你主动填写的说明，可以由你导出；没有远程收件端，不会自动发送给开发者。本机技术诊断可关闭，默认不记录简历正文、照片及联系方式。

## 9. 后续升级与源码

同包名、同签名的新版 APK 可以覆盖安装并保留资料；不同签名不能直接覆盖。升级前仍建议导出备份。

`简历工坊-1.0.0-源码.zip` 包含本应用源码、静态依赖及对应许可，不包含签名私钥、密码或个人资料。在另一台机器自行重新签名构建的 APK，通常不能直接覆盖已安装的原签名版本；需要原签名持有者用原私钥制作兼容升级包。
