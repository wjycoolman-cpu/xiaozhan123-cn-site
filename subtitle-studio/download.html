中英字幕工坊在线编辑

Windows 版

中英文声音识别、离线双语翻译、多字体与字幕模板、时间校对、实时预览，以及快速 MP4 导出。

下载 Windows 软件包

Windows 10 / 11 · 64 位 · 无需安装 Python · 免费

开始使用

  1. 下载并解压整个 ZIP 文件。
  2. 打开其中的 SubtitleStudio.exe，软件会显示本机编辑器。
  3. 选择视频，点击“识别声音”。首次需要联网下载模型，以后同模型可离线使用。
  4. 校对字幕，生成另一语言，调整字体与位置，导出字幕或带字幕 MP4。

选择合适的识别质量

快速档适合初稿；均衡档默认使用 small 量化模型；精细与最高精度使用更大模型，耗时和内存占用也更高。嘈杂音轨、方言、人名和数字需要人工校对，不保证所有视频识别无误。

网页版与 Windows 版

两者均在本机处理音视频。网页版使用浏览器支持的音视频格式与 ONNX 模型，导出成片是按播放时长录制 WebM；Windows 版使用 faster-whisper 和 FFmpeg，适合长视频和快速 MP4 导出。首次下载模型、字体和更新包需要网络。

识别、翻译、字体、视频处理组件的来源与许可见 开源组件说明。反馈默认保留本机，导出后可交给开发者。
