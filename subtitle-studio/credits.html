中英字幕工坊：组件与字体

本软件不上传音视频或字幕。模型下载从公开来源取得权重并在本机运行，不执行模型仓库的远程 Python 代码。

  • faster-whisper — MIT；本机声音识别，Whisper 模型来自 Systran/OpenAI。
  • CTranslate2 — MIT；量化推理。
  • Argos Translate — MIT；中英翻译模型。主源失效时采用固定提交的 公开模型镜像，解包检查语言身份，模型训练质量独立于软件功能。
  • Transformers.js 3.8.1 — Apache 2.0；网页版 Whisper / OPUS-MT ONNX 模型，本机浏览器运行。ONNX Runtime — MIT；WASM 模块来自固定版本 jsDelivr CDN。
  • SentencePiece — Apache 2.0；翻译分词。
  • OpenCC — Apache 2.0；中文简繁规范化。
  • Noto Sans SC、Noto Serif SC — SIL OFL 1.1；Adobe/Google。黑体许可、宋体许可。
  • LXGW WenKai 1.522 — SIL OFL 1.1，源自 Fontworks Klee One；文楷许可。字体不单独售卖；本软件没有得到字体作者背书。
  • FFmpeg — Windows 软件包所带 Gyan 9.0.1 full build，GPL v3 及其依赖许可；用于成片导出。原构建、源代码及配置说明；FFmpeg 对应源代码。组件独立进程调用；软件包保留开源许可和使用说明。
  • Flask / Werkzeug — BSD 3-Clause；PyAV — BSD 3-Clause；PyInstaller — GPL with bootloader exception；cryptography — Apache 2.0 / BSD。
