# 眠迹 HTML 演示候选 · 对照正式 APP 1.1.2

## 集成

将本目录原样作为独立静态目录部署，例如 `/mianji/demo/`，入口为 `index.html`。所有应用资源使用相对路径，无构建依赖。由网站 owner 集成及发布；本任务没有修改网站全局 app.js、目录或主页面。

## 对照依据

Android 正式版 1.1.2 / code 4 的 SleepUi.kt 和真实模拟器运行页面。保留监测、趋势、我的三个页面、原配色和月亮图形、对应 Material 图标、七天和三十天图表、日记、参考线、记录编辑与确认。

同条件比较采用上海时区、Android 1080×2400 / density 420，去除系统状态栏及导航栏后归一到 412×841。证据及结果在本项目 work/qa/html-parity-report.json。Android 与浏览器字体渲染、系统日期/时间控件和弹窗仍有平台差异；并非像素级相同。

## 数据与功能边界

- 初次进入默认自动推测开关开启、无记录；浏览器没有手机使用权限，点击一键开启说明 Android 授权限制。
- 浏览器独立存储键 `mianji-html-parity-1.1.2-v1`。补记、修改、排除/重新计入、删除、清空及参考线调整仅影响网页数据。
- 查看独立示例包含十四条虚构记录，退出后不写入自己的日记。示例中记录及设置不能修改。
- 反馈只保存演示内容，不发送正式反馈服务；发送后的提示明确说明没有投递。
- 导出、备份、恢复和安装更新保留入口并解释限制：本候选没有移植 Android 文件保存/选择器，不读取真实手机备份，也不能安装 APK。网页文件导出/导入未实现，不能宣称与 Android 全部能力等价。
- app.js 没有 fetch、XHR 或原生桥。字体资源来自官方 fonts.gstatic.com；这是 UI 资源请求，不含睡眠数据。无正式反馈 POST 或手机数据访问。

## 字体与图标

Roboto、Noto Sans SC 通过 fonts.css 引用官方在线资源，离线时退回系统无衬线字体，外观可能有差异；交付不附带字体二进制。图标 SVG 取自 Material Design Icons，Apache 2.0；许可证保留在 assets。Google Fonts 的 OFL 文本也保留。月亮图形按 APP 中数学图形移植。
